1. Application Description 
This project is an online crystal shopping website developed using Django. The website is designed to display and sell different types of natural crystal products, such as amethyst, rose quartz, clear quartz. Users can browse products, view product details, register and log into accounts, add items to a shopping cart, and place orders.

2. Authentication and Authorization Scheme 
The system uses Django’s built-in Authentication System to implement user authentication and permission management.
Users are required to log in using a email and password.

| User Group | Permission Description                                      |

| Guest          | Browse products and view product details            |
| Customer    | Log in, place orders, manage shopping cart, and view orders |
| Superuser    | Has full system permissions, including Django Admin access  |
